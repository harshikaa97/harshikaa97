## <img src="https://media.giphy.com/media/WUlplcMpOCEmTGBtBW/giphy.gif" width="28"> Featured Projects

<details open>
<summary><b>📌 ExamGuard AI — RAG-Powered Exam Paper Generation Platform</b></summary>
<br/>

> An end-to-end retrieval-augmented generation platform that ingests course material and generates structured exam papers. Built to move past notebook prototypes into a real deployable system — typed backend, vector retrieval, and a proper frontend, not a Streamlit demo.

| Aspect | Details |
|---|---|
| **Stack** | FastAPI, Next.js, FAISS, Groq (Llama-3.1-8B-Instant), Gemini Embeddings, PyMuPDF |
| **Status** | 🚧 Active development |
| **Architecture** | RAG pipeline — PDF extraction → vision-OCR fallback → embedding → FAISS retrieval → LLM generation |
| **Repository** | [github.com/harshikaa97/examguard](https://github.com/harshikaa97/examguard) |

Started as a capstone for the Kaggle × Google 5-Day AI Agents Intensive, rebuilt from the ground up with a production-oriented stack — FastAPI backend, Next.js frontend, Groq for low-latency inference. Focus is correctness of retrieval over flashy output: wrong context in, wrong exam paper out.

</details>
